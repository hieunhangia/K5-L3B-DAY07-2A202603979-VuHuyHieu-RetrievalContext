### Phân tích chi tiết 2 ca lỗi trên Dev

#### **Ca lỗi 1: Hiện tượng "Semantic Attraction" ở câu `q01` (Điều kiện học bằng kép)**
- *Hiện tượng:* Ở Dense Baseline, chunk Rank 1 rơi vào Trang 21 (`vinuni_qd_073` - Quy định công nhận tốt nghiệp chương trình thứ hai) với cosine = 0.865, đẩy chunk chứa gold evidence ở Trang 4 (`quy_che_dao_tao_vinuni_2024_stratC_p4_c003` - Điều kiện đăng ký học cùng lúc hai chương trình) xuống Rank 2 (cosine = 0.841). Kết quả: `Hit@1 = False`.
- *Nguyên nhân gốc rễ:* Cụm từ "học cùng lúc hai chương trình" xuất hiện lặp lại ở cả hai trang; vector embedding ngữ nghĩa vĩ mô bị thu hút vào mật độ từ vựng học thuật cao ở trang tốt nghiệp. Trong khi đó, BM25 bắt chính xác các từ khóa định danh "được cấp bằng kép", "đăng ký chương trình thứ hai" và xếp Trang 4 ở Rank 1.
- *Khắc phục & Kết quả:* Sử dụng **Weighted Hybrid RRF ($w_{bm25}=0.70, w_{dense}=0.30, k=20$)** đã đẩy chunk Trang 4 lên Rank 1 chung cuộc, đưa `Hit@1` của `q01` thành `True`.

#### **Ca lỗi 2: Hiện tượng "Context Budget Bottleneck" ở câu `q03` (Giờ tự học định mức 1 tín chỉ)**
- *Hiện tượng:* Cả Dense và BM25 đều xếp đúng chunk Trang 9 (`quy_che_dao_tao_vinuni_2024_stratC_p9_c001`, chứa bằng chứng "30 giờ tự học") vào Rank 2. Tuy nhiên, chunk Rank 1 (Trang 8, định nghĩa chung về tín chỉ) dài 782 ký tự. Khi thêm header metadata (~80 ký tự), tổng độ dài khối chunk đầu tiên là 862 ký tự > 800 ký tự. Hàm `pack_context()` ngắt ngay lập tức, làm mất chunk Rank 2. Context gửi cho Agent không có đáp án $\to$ `Context Evidence Rate = False`.
- *Nguyên nhân gốc rễ:* Ngân sách 800 ký tự quá chật hẹp so với kích thước thực tế của văn bản quy chế.
- *Khắc phục & Kết quả:* Tăng ngân sách lên `budget=2000` ký tự (Cải thiện 1 & Cải thiện 2). Toàn bộ 2–3 chunk hàng đầu được đóng gói nguyên vẹn (~1520 ký tự), giúp `Context Evidence Rate` đạt 100.0%.

### Lý do lựa chọn và Khóa cấu hình (Locked Selected Config)
- Cấu hình **Weighted Hybrid RRF ($k=20, w_{bm25}=0.70, w_{dense}=0.30$) kết hợp `budget=2000`** đạt chất lượng vượt bậc: `Hit@1 = 86.7%` trên Dev, `Hit@3 = 100%`, `Context Evidence Rate = 100%`.
- Độ trễ tăng thêm chỉ ~0.5ms (hoàn toàn không đáng kể so với vài giây của LLM), chi phí chỉ tăng thêm ~300 tokens cho prompt. Toàn bộ tham số được **KHÓA CỐ ĐỊNH** trước khi chạy trên Test set.

## 3. Agent và đánh giá

- **Tool, số lượt gọi, điều kiện dừng, cách chọn context và xử lý lỗi:**
  - *Tools:* Hệ thống triển khai Function Calling chuẩn mực gồm 2 tools:
    1. `search(query: str)`: Cho phép agent tìm kiếm dữ liệu từ retriever với truy vấn ngữ nghĩa hoặc từ khóa.
    2. `answer(answer: str, citations: list[str])`: Trả lời câu hỏi kèm danh sách mã chunk trích dẫn `[chunk-id]`.
  - *Số lượt gọi:* Cho phép tìm kiếm tối đa `max_searches = 3` turns.
  - *Điều kiện dừng:* Dừng ngay khi gọi tool `answer`, hoặc dừng từ chối khi chạm giới hạn lượt tìm kiếm (`max_searches`), hoặc khi context sau tìm kiếm không chứa bằng chứng.
  - *Context packing & Trích dẫn:* Đóng gói khử trùng lặp qua `pack_context`, bảo toàn metadata `[{id} | {source} | page {page}]`. Agent bắt buộc trích dẫn đúng mã chunk `[chunk-id]` có mặt trong context; nếu trích dẫn mã ảo hoặc không khớp văn bản, cơ chế validation sẽ phát hiện và chuyển sang từ chối an toàn.

## 5. Hướng dẫn Tái lập (Reproducibility Guide)

Mọi kết quả trong báo cáo này đều có thể tái lập hoàn toàn từ mã nguồn với các lệnh sau:

### 1. Chuẩn bị môi trường
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Điền GOOGLE_API_KEY / GEMINI_API_KEY và OPENAI_API_KEY vào .env
```

### 2. Chạy toàn bộ Unit Tests kiểm tra tính toàn vẹn hệ thống
```bash
python3 -m unittest discover tests -v
# Kết quả mong đợi: 23/23 tests pass
```

### 3. Tái lập Benchmark Retrieval trên Dev (3 Phương pháp & 2 Cải tiến)
```bash
python3 src/run_stage4_experiments.py
# File output: results/stage4_dev_comparison.json, results/stage4_error_analysis.json
```

### 4. Tái lập Đánh giá Agent trên Test set (Baseline & Cấu hình đã chọn)
```bash
python3 src/run_stage5_test_eval.py
# File output: results/test_traces_baseline.json, results/test_traces_selected.json
```

### 5. Chạy tổng hợp Metrics chuẩn với `agent_metrics.py`
```bash
python3 starter/agent_metrics.py \
  --cases data/agent_cases.json \
  --traces results/test_traces_selected.json \
  --reviews results/test_reviews_selected.json \
  --split test \
  --output results/summary_test.json
```
